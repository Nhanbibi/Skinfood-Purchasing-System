# Skinfood-Purchasing-System
Phân tích và thiết kế hệ thống quản lý mua hàng tập trung cho chuỗi cửa hàng Thế Giới Skinfood, bao gồm khảo sát quy trình nghiệp vụ, xác định yêu cầu chức năng và phi chức năng, xây dựng các mô hình UML, thiết kế cơ sở dữ liệu 19 bảng và giao diện hệ thống trên Figma. Công cụ sử dụng gồm Enterprise Architect, Draw.io, Figma và SQL Server.
